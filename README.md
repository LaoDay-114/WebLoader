# WebLoader
WebLoader, a fast and modern dynamic web injector.

---

## 快速入门
这无疑是简单的，但是你需要前置条件。

1. Node.js

没了，就这些，这无疑是让我兴奋的。

推荐在本仓库的 Releases 中下载 WebLoader-x.x.x-with-dep.zip , 不然你就要自己配置一份了。

> [!WARNNING]
> Releases 中发布的 zip 中附带的依赖仅支持 x64-Windows 如果是其他平台，需要 clone 一份源码安装依赖！

#### 小贴士
> 如果你要 fork 的话你应该也知到 GPLv3 许可证的

下载完后随便解压到一个路径，最好不要有中文。

将解压出来的 WebLoader 的路径添加到 PATH 中.

就可以使用 WebLoader 了。

使用下面的命令在当前目录为指定网站安装 WebLoader:
```bash
WebLoader install https://www.bilibili.com/
```
其他写法请查看 WebLoaderAPI.md
